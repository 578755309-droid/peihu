# 服务填写信息与三端字段核对

核对范围：当前代码中 11 个陪诊项目、住院陪护、居家陪护、上门助浴；另核对助浴十次套餐、次卡兑换及续约。以现有填写界面和提交校验为依据，不增加新的收费项目、必填项或派单规则。

## 每个项目的填写项

通用档案：姓名、身份证号码、由身份证识别的性别/年龄、健康情况及服务需求。下单使用已有档案或新增档案。三端详情仅显示脱敏身份证，不展示完整号码。

通用联系人：姓名、电话；接送项目仅要求电话。

护理需求：自理能力、管路、传染性疾病、皮肤破损；有传染性疾病时填写名称。陪诊下单不展示这些选择，三端不再给陪诊套用默认“完全自理/无”。

| 项目 | 档案/联系人 | 时间、地点与专属信息 | 备注及校验 |
| --- | --- | --- | --- |
| 住院陪护 | 通用档案、通用联系人、护理需求 | 医院、科室、床位号、开始日期、陪护天数 | 科室与床位必填，其他诉求选填 |
| 居家陪护 | 通用档案、通用联系人、护理需求 | 服务地址、开始日期、陪护天数 | 其他诉求必填，没有需填写“无” |
| 上门助浴单次 | 通用档案、通用联系人、护理需求 | 服务日期、时段、服务地址、次数；可选护理员，最多两位 | 其他诉求选填 |
| 上门助浴十次套餐 | 同上 | 总次数10；可主动逐次添加日期/地址，也可购买后预约；余下次数进入卡包 | 没有预约不显示虚构日期；已预约明细显示各次地址和联系人 |
| 助浴次卡兑换 | 卡片锁定的服务对象，沿用首购健康情况、护理需求及联系人 | 选择卡片、服务日期、时段、服务地址 | 首购缺失的信息明确显示未填写，不套用当前页面默认护理需求 |
| 贵宾陪诊 | 通用档案、通用联系人 | 服务医院、检查项目、服务日期 | 检查项目必选，备注选填 |
| 优享陪诊 | 通用档案、通用联系人 | 服务医院、检查项目、服务日期 | 检查项目必选，备注选填 |
| 代约检查 | 通用档案、通用联系人 | 检查项目、服务日期、服务地址 | 检查项目必选，备注选填 |
| 代看检查结果 | 通用档案、通用联系人 | 已有检查单图片（最多3张）、服务日期、服务地址 | 备注必填；原流程不强制上传图片，保持不变 |
| 代办住院手续 | 通用档案、通用联系人 | 服务日期、服务地址、服务科室 | 科室原流程选填，备注选填 |
| 代办出院手续 | 通用档案、通用联系人 | 服务日期、服务地址、服务科室 | 科室原流程选填，备注选填 |
| 代买药 | 通用档案、通用联系人 | 买药地址、送达地址、服务日期 | 两个地址必选，其他诉求选填 |
| 代取报告 | 通用档案、通用联系人 | 报告名称、服务日期、服务医院（选填）、邮寄地址 | 报告名称和邮寄地址必填，备注选填 |
| 三环内接/送患者 | 接送人档案、联系电话 | 上车地址、送达地址、日期、乘车人数 | 联系人姓名隐藏；备注选填 |
| 机场接/送患者 | 接送人档案、联系电话 | 接机地址、送达地址、日期、乘车人数 | 联系人姓名隐藏；备注选填 |
| 西安北站接送患者 | 接送人档案、联系电话 | 接站地址、送达地址、日期、乘车人数 | 联系人姓名隐藏；备注选填 |

所有新订单仍要求勾选对应知情同意书；检查项目“其他检查”沿用现有自定义文本输入。日期/时段以现有时间选择器提供的项目为准。通用服务档案里的健康情况仍是现有必填项。

## 本轮修复

- 健康情况从档案进入订单快照，不再只保留于档案页面。
- 三端采用同一字段映射，不再使用固定示例护理需求覆盖实际订单。
- 护理员详情根据 URL 订单号读取实际对象、地址和服务项目；找不到记录时显示空状态。
- 原护理员示例订单共享同一份数据，避免不同订单详情都显示李先生。
- 护理员列表读取已分配给当前示例护理员的本地下单记录，支持两人助浴；不把用户应付金额当作护理员收入。
- 护理员新增记录入口及日志页关联真实订单号，不再固定指向示例订单；其他订单不显示示例护理历史。
- 续约复制适用的档案、健康、联系人及专属字段，并更新日期和地址。
- 次卡兑换沿用关联首购订单的健康和联系人信息；首购记录缺失时不虚构默认值。
- 助浴套餐首个预约订单保留用户备注，并使用该次预约实际地址。

## 验证与限制

`node tests/service-fields.test.cjs` 对14个基础项目逐项写入不同健康情况、备注和专属字段，读取用户/护理员/后台详情并逐字段比对；另外核对套餐、次卡、护理员路由、脱敏和空状态。原有协议勾选、检查项目、卡片切换及公共交互测试一并回归。

旧订单没有保存过的字段显示“未填写”，不会根据当前档案反推历史健康情况。页面沿用浏览器本地订单存储，跨设备三端同步仍需后台接口；本轮验证的是同一数据源内的字段完整性。未增加服务端角色权限、派单或收入结算逻辑。浏览器视觉验收在当前环境不可用。
