# 佑康・绿通卡 · 本期交互原型

入口：`youkang.html`（用户端）、`admin-youkang.html`（后台）、`nurse-youkang.html`（陪护端）。原首页、我的、卡包、订单及后台导航已接入入口；服务目录新增“体检服务”。

本期只有1698元固定套餐：体检1333元、陪同299元、绿通代约66元。不含额外加项。医院固定为西安交通大学第一附属医院体检中心。男女项目各16项，保留提供的单价；项目参考价合计分别为1335.5元、1325.5元，与套餐基础价分开。检查意义由后台录入医院确认的说明，未录入前前端提示以体检中心说明为准。

支付成功发卡并标VIP；付费卡、免费奖励卡发放后有效期2年。购买时保存项目快照，后续配置不会改写已有订单。奖励卡保存发卡时项目快照。

流程：购买（原型模拟支付）→我的卡→预约→后台分配已认证在岗陪诊员→陪护端开始服务→服务中提交记录→客户出示6位核销码→陪诊员填写完成说明并核销→已完成。未预约不能分配；非本人分配订单不能操作；已使用/已预约/过期卡不能再次预约。

奖励仅一级直推，A需先付费成为VIP。A的直推客户付费购卡且体检核销完成后计数，每位客户只计一次。每满3位，自动发1张同权益免费卡；6位发2张，可循环。二级及以下、未完成订单、重复客户和免费卡订单均不计数。既有推荐关系保留，禁止自推、循环关系和购买后补绑；重复支付/核销不会重复发卡。

分享页有专属推广链接、真实QR码和750×1120 PNG海报下载。使用本地file地址时，需发布到可访问域名后再对外扫码。未发布的本地链接仅用于演示。

后台“原型账号预览”可创建新的演示客户、填写一级推广码，并切换账号验证多轮推荐。护理员身份沿用原认证流程。所有原型数据使用当前浏览器本地存储；支付、医院排期、跨设备好友数据同步、账户权限校验需正式服务端与小程序支付接入，当前未产生真实支付或医院预约。
